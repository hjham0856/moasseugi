# 브레인라이팅 클릭형 HTML 데모

`index.html`을 브라우저에서 열면 됩니다. 각 화면은 개별 HTML 파일로 분리되어 있으며 별도의 서버, 패키지 설치, API 연결은 필요하지 않습니다.

- 진행자: 홈 → 안건 생성 → 공유/관리 → 작성/평가 → 결과 → 최종 채택
- 참가자: 닉네임 입장 → 안내 → 작성 → 평가 → 결과
- 상단 `데모 화면` 메뉴에서 진행자·참가자 흐름을 선택할 수 있습니다. `오류 화면`에 커서를 올리면 아이디어 없음, 참가 불가, 잘못된 링크, 권한 없음, 연결 끊김, 저장 실패, 재접속 오류가 나타납니다.
- 헤더에는 이름과 로그아웃 버튼이 있습니다. 진행자의 안건은 홈 오른쪽 목록에서 확인합니다.

## 디자인 구조

루트의 `design.md`를 기준으로 화면들이 동일한 색상, 타이포그래피, 간격, 상태 표현을 공유합니다. 홈은 서비스 설명과 진행자의 안건 목록을 함께 보여주고, 작성·평가·결과 화면은 현재 단계의 행동에 집중합니다. 공통 토큰은 `tokens.css`, 화면 스타일은 `styles.css`, 화면 이동 로직은 `app.js`에 있습니다.

## 화면별 HTML

- `index.html` — 진행자 홈·내 안건
- `login.html` — 로그인 예시 화면
- `signup.html` — 회원가입 예시 화면
- `demo-state.html` — 아이디어 없음·참가 불가·접근 및 연결 오류 화면
- `dashboard.html` — 이전 주소에서 홈으로 이동
- `create-session.html` — 새 안건 만들기
- `lobby.html` — 세션 공유·대기실
- `writing-control.html` — 작성 단계 관리
- `join.html` — 닉네임 입장
- `guide.html` — 참가자 안내
- `writing.html` — 아이디어 작성
- `evaluation.html` — 아이디어 평가
- `results.html` — 평가 결과
- `selection.html` — 최종 채택
- `final-result.html` — 최종 결과

모든 입력값과 결과는 고정된 예시입니다. 버튼은 화면 전환, 선택 표시, 모달, 토스트만 동작하며 네트워크 요청은 보내지 않습니다.
